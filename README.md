# مفاجأة عيد ميلاد يا رفووووووق ❤️ — المرحلة الأولى

موقع مفاجأة شخصي واستقبال رومانسي لخطيبتك (رفوووووق)، مصمم بالكامل بالعامية المصرية الدافية، باتجاه عربي سليم (RTL)، ومبني وفق معيار **Mobile-First** ليعمل بأعلى سلاسة وتناسق بصري على شاشات الهواتف وأجهزة الكمبيوتر.

---

## 🌟 مميزات المرحلة الأولى (Phase 1)

1. **واجهة ألبوم صور ليلي دافي (Night Album Ambiance):**
   - خلفية كحلية ليلية عميقة مستوحاة من سماء الليل مع نجوم متلألئة وغبار ذهبي ناعم.
   - إطار كريمي دافي بنمط البولارويد وألبومات الذكريات الكلاسيكية، مزود بزوايا تثبيت نحاسية وشارة تاريخ خاصة.
   - **الصورة الافتتاحية (Hero Selfie):** مضبوطة بدقة بحيث تظهر الابتسامة وملامح الوجهين، مع إبراز اليدين والدبل الذهبية كاملة دون أي اقتطاع على كل الشاشات.

2. **نصوص وذكريات حميمية:**
   - **العنوان الرئيسي:** `يا رفووووووق ❤️` (مع الحفاظ الدقيق على رسم اسم الدلع).
   - **النص الترحيبي:** «فاضل شوية على عيد ميلادك… وقبل ما ييجي، عايز أرجع معاكي ليوم بحبه أوي».
   - **التاريخ على الإطار:** «٢٣ نوفمبر».
   - **نص الذكرى أسفل الصورة:** «فاكرة يوم ما أبونا صلّى على الدبل، وبعدها نزلنا أول ديت؟ كل ما ببص للصورة دي ببتسم».

3. **عدّاد تنازلي دقيق وثابت بتوقيت القاهرة:**
   - ينتهي العد التنازلي بدقة مع بداية يوم **٢ ديسمبر ٢٠٢٦، الساعة ٠٠:٠٠ بتوقيت القاهرة (`UTC+02:00`)**.
   - **مستقل عن المنطقة الزمنية لجهاز الزائرة:** مهما كانت الدولة أو المنطقة الزمنية على موبايل خطيبتك (مصر، الخليج، أوروبا، أمريكا)، فإن فارق التوقيت يُحسب بالمللي ثانية الموحدة بالنسبة لتوقيت القاهرة.
   - **أرقام ثابتة العرض (`tabular-nums`):** بطاقات العدّاد لا تهتز ولا يتغير حجمها إطلاقاً أثناء تغيّر الثواني أو الدقائق.

4. **حالة الاحتفال التلقائية عند الصفر (Celebration State):**
   - عند وصول العدّاد إلى الصفر (سواء كانت الصفحة مفتوحة بالفعل أو فُتحت بعد حلول الموعد)، يتحول العدّاد بسلاسة إلى كارت احتفال رومانسي متوهج.
   - **رسالة التهنئة:** `كل سنة وإنتِ طيبة يا رفووووووق ❤️`
   - إطلاق تأثير ألعاب نارية ونجوم متلألئة وقلوب تتطاير في الخلفية عبر Canvas.

5. **سهولة التعديل والتخصيص الفائق (Modular Config):**
   - كافة النصوص، التواريخ، ومسارات الصور مجمعة في ملف مستقل `config.js` لتعديلها في ثوانٍ دون لمس الأكواد.
   - تم تخصيص وتسمية صور الألبوم الثلاث الأخرى داخل مجلد `assets/images` للمرحلة القادمة:
     - `photo-1-mirror.jpg` (صورة المراية)
     - `photo-3-selfie-rings-2.jpg` (السيلفي الثانية بالدبل)
     - `photo-4-group-father.jpg` (الصورة الجماعية مع أبونا)

## 🚀 خطوات التشغيل والاستعراض المحلي

المشروع مبني بأسلوب Web Standards نقي بدون أي مكتبات ثقيلة أو خطوات بناء (Build steps):

### الطريقة الأولى: الفتح المباشر
- يمكنك ببساطة النقر المزدوج على ملف `index.html` ليفتح في أي متصفح (Chrome, Edge, Safari, Firefox).

### الطريقة الثانية: عبر خادم محلي (موصى به)
باستخدام بايثون المدمج:
```powershell
# من داخل مجلد المشروع:
python -m http.server 8080
```
ثم افتح في المتصفح:
- الموبايل / الكمبيوتر: `http://localhost:8080`

## 🧪 أدوات الاختبار وتجربة الحالات

للتسهيل عليك أثناء مراجعة الموقع قبل إطلاقه:

1. **عبر لوحة التحكم المدمجة:**
   - ستجد زراً صغيراً في الركن العلوي الأيسر: `⚙️ تجربة الحالات`.
   - يتيح لك التبديل بنقرة واحدة بين:
     - **التوقيت الفعلي** (العدّاد الحي المتبقي حتى ٢ ديسمبر).
     - **تجربة ٥ ثوانٍ للصفر** (لمشاهدة لحظة وصول العدّاد إلى الصفر وانتقاله التلقائي للاحتفال دون انتظار).
     - **معاينة عند الصفر (الاحتفال)** (رؤية كارت التهنئة وتأثير القلوب والقصاصات).

2. **عبر معلمات الرابط (URL Parameters):**
   - لمعاينة شاشة الاحتفال مباشرة: `index.html?test=ended`
   - لتجربة عدّاد ٥ ثوانٍ: `index.html?test=5s`

3. **تشغيل الاختبارات الآلية:**
```powershell
python test_suite.py
```
يقوم هذا الاختبار بالتحقق التلقائي من:
- تطابق جميع النصوص المطلوبة وحروف الدلع.
- دقة حساب توقيت القاهرة عبر ٧ مناطق زمنية مختلفة حول العالم.
- التقاط لقطات شاشة دقيقة للأجهزة المختلفة وحفظها.
