# مفاجأة عيد ميلاد يا رفووووووق ❤️ — المرحلة الثانية: ألبوم الذكريات وظرف ٢٣ نوفمبر


---

## 🌟 الجديد في المرحلة الثانية (Phase 2)

1. **ظرف واحد موحّد («ظرف ٢٣ نوفمبر»):**
   - تم تصميم ظرف كلاسيكي رومانسي أنيق بلون عاجي وختم شمعي أحمر وذهبي يحمل عبارة «٢٣ نوفمبر».
   - يحكي قصة اليوم المشترك: صلاة الدبل وأول ديت بعد الخطوبة.
   - **قبل الموعد:** تظل واجهة الاستقبال والعدّاد الحي وصورة الافتتاح واضحة ونشطة.
   - **عند حلول الموعد (٢ ديسمبر ٢٠٢٦، الساعة ٠٠:٠٠ بتوقيت القاهرة) أو عند الزيارة/التحميل بعده:** يظهر كارت التهنئة المتوهج ومعه زر:
     > **«افتحي ظرف ٢٣ نوفمبر 💌»**

2. **ألبوم الذكريات المكوّن من ٤ صور بالترتيب المحدد:**
   - **الصورة ١:** الصورة الجماعية مع أبونا — «يوم ما أبونا صلّى على الدبل» *(مضبوطة بنمط `contain` لضمان ظهور كل الأشخاص دون اقتطاع أطراف الصورة)*.
   - **الصورة ٢:** صورة المراية — «أنا وإنتِ يوم ٢٣ نوفمبر».
   - **الصورة ٣:** السيلفي الافتتاحية مع الدبل — «وبعدها نزلنا أول ديت».
   - **الصورة ٤:** السيلفي التانية بالدبل — «كل ما أبص للصور دي ببتسم. بحبك يا رفووووووق ❤️».

3. **تجربة تنقل سلسة تدعم اللمس والكيبورد:**
   - أزرار عربية واضحة: **«السابق»** و**«التالي»**، مع مؤشرات دوائر تفاعلية (Dots indicator).
   - دعم كامل للسحب باللمس على شاشات الموبايل (Touch Swipe).
   - دعم لوحة المفاتيح: السهم لليسار (التالي في RTL)، السهم لليمين (السابق)، وزر `Escape` للإغلاق.
   - حركة فتح الظرف خفيفة مع احترام كامل لإعدادات تقليل الحركة (`prefers-reduced-motion`).

4. **إصلاحات وتدقيق المرحلة الأولى:**
   - **حماية روابط الاختبار وعزلها:** زر «تجربة الحالات» ومعاملات الرابط (`?test=...`) متاحة حصرياً للمطور محلياً، ولا تظهر إطلاقاً للزائرة؛ وضع الزائرة (`?mode=visitor`) يتجاهل تماماً أي روابط اختبار ويثبت العدّاد الفعلي.
   - **ضبط آخر ثانية ولحظة الصفر:** عند وصول العدّاد للصفر والصفحة مفتوحة، تُعرض الأصفار أولاً `00:00:00:00` مع نبضة ضوئية رقيقة، ثم تنتقل بسلاسة للاحتفال وظهور زر الظرف.
   - **مستقل تماماً عن المنطقة الزمنية:** تم اختباره والتأكد من دقته عبر مناطق زمنية متعددة (القاهرة UTC+2، نيويورك UTC-5، لندن UTC+0، طوكيو UTC+9).

## 🧪 أدوات المراجعة واختبار الحالات

1. **الزر المدمج للمطور محلياً (`⚙️ تجربة الحالات`):**
   - **التوقيت الفعلي (قبل الموعد):** يعرض العدّاد الحقيقي المتبقي حتى ٢ ديسمبر ٢٠٢٦.
   - **تجربة عدّاد ٣ ثوانٍ للصفر:** لمشاهدة لحظة العد التنازلي والوصول للصفر وانبثاق الاحتفال والظرف.
   - **معاينة عند الصفر (ظرف ٢٣ نوفمبر):** يفتح كارت التهنئة ومكوّن الظرف فوراً.
   - **فتح الألبوم مباشرة:** يستعرض نافذة الألبوم الأربع صور لتجربة التنقل واللمس.

2. **تشغيل الاختبارات الآلية:**
```powershell
python test_suite_phase2.py
```
يقوم هذا السكريبت باختبارات فعلية في المتصفح عبر Chrome Headless + CDP، مع التحقق من نصوص الإعدادات، وأمان وضع الزائرة، ومطابقة الصفر، والتنقل في الصور الأربع، وغياب التمرير الأفقي.
